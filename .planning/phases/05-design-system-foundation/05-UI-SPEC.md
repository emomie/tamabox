## Token File Contract

### File Inventory (post-Phase-5)

| File | Location | Purpose |
|------|----------|---------|
| `tokens.css` | `webroot/css/tokens.css` | Primary token layer — all `--tb-*` variables + `.tb-*` utility classes. Copied verbatim from `handoff_tamabox/tokens.css` (259 lines) |
| `colors_and_type.css` | `webroot/css/colors_and_type.css` | Semantic alias layer — `--fg-*`, `--bg-*`, `--accent`, `--type-*`. The preferred API for Phase 6+ templates |
| `tamabox.css` | `webroot/css/tamabox.css` | Existing file — `:root` block replaced with Calm Gacha aliases; legacy class names aliased; new `.tb-*` component CSS appended in Phase 5 section |

### CSS Load Order in `layout/default.php`

The `Html->css([ ])` array must be updated to exactly this order:

```php
$this->Html->css(['normalize.min', 'milligram.min', 'tokens', 'colors_and_type', 'tamabox'])
```

**Rationale:** `normalize` resets browser defaults → `milligram` provides grid/base typography → `tokens` declares `--tb-*` primitives → `colors_and_type` declares semantic aliases using `@import url('tokens.css')` (the `@import` line must be removed when serving separately; both files are served by CakePHP's `Html->css()` chain, so the import is redundant and must be stripped from the production copy of `colors_and_type.css`) → `tamabox` consumes both layers and provides page-level component styles.

### Google Fonts `<link>` Tag

Add this `<link>` element in `<head>` of `layout/default.php`, before the `Html->css()` call:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@500&family=Noto+Sans+JP:wght@400;700&display=swap" rel="stylesheet">
```

## Color

Source: `handoff_tamabox/tokens.css` — values are verbatim hex from that file.

### 60/30/10 Split

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) — page surface | `#FFFFFF` (`--tb-paper`) | Page background, card surfaces, AppBar background |
| Secondary (30%) — recessed surfaces | `#F6F7F8` (`--tb-card-soft`) / `#F2F3F4` (`--tb-paper-deep`) | Input fields, soft cards, disabled button bg, tab bar frosted glass substrate |
| Accent primary (10%) — turquoise | `#2FA597` (`--tb-turq-400`) | Primary buttons, active tab indicator, focus rings, links, CTA fill |
| Accent secondary — honey | `#D9A23C` (`--tb-warm-500`) | Letter card left border, char counter (normal), warm chip background via `--tb-warm-100` |
| Destructive | `#B84238` (`--tb-danger`) | Danger button fill, destructive form labels, block confirm CTA |

**Accent turquoise reserved for:** primary `.tb-btn--primary` background, `.tb-tabbar__item.is-active` text color (`--tb-turq-500`), `:focus-visible` outline, `.tb-input:focus` border, `.tb-chip` (default tone) background via `--tb-turq-50`, sender handle color.

## Copywriting Contract

Phase 5 adds no new user-facing strings (no screens change). However, the following copy elements are defined here as the source of truth for Phase 6+ implementation.

**Design System writing principles (from `handoff_tamabox/DESIGN_SYSTEM.md`):**
- Voice: 静かな日本語 — calm, no hype, no exclamation
- No emoji anywhere except `✦` (U+2726) for SSR HIT / Onboarding final step only
- Numbers and handles always in JetBrains Mono (`tb-mono` class)
- CJK + latin boundaries: always add half-width space (例: "SSR 10%", "5/12 · 09:41")
- Labels: lowercase + uppercase via CSS `text-transform: uppercase` + `letter-spacing: 0.2em`
