# Plan 08-02 — EDGE-01: 404 error page rewrite to hi-fi SendNotFound

## Goal

Replace the default CakePHP 404 error template (`templates/Error/error400.php`) with a Calm Gacha hi-fi `SendNotFound` layout, and migrate the error layout chain (`templates/layout/error.php`) from legacy Milligram CSS to the tokens.css + tamabox.css chain. Every CakePHP 400-class error now renders the same hi-fi screen (D-01 single-pattern simplification).

## Tasks

1. Re-read `08-UI-SPEC.md` §"Component 2 — `templates/Error/error400.php` (EDGE-01)" and hi-fi `SendErrors.jsx` lines 9-64.
2. Open `templates/layout/error.php`:
   - Replace `<?= $this->Html->css(['normalize.min', 'milligram.min', 'fonts', 'cake']) ?>` with `<?= $this->Html->css(['normalize.min', 'milligram.min', 'tokens', 'colors_and_type', 'tamabox']) ?>`.
   - Remove the trailing `<?= $this->Html->link(__('Back'), 'javascript:history.back()') ?>` (the body template provides its own CTAs).
   - Keep the `<?= $this->Flash->render() ?>` line (defensive).
   - Keep `lang="ja"` if not present (CONTEXT consistency).
3. Open `templates/Error/error400.php`:
   - Keep the `$this->layout = 'error';` + debug-mode dev_error branch (top of file, lines 1-37 of current).
   - Replace lines 38-42 (the `<h2>` + `<p class="error">` block) with the hi-fi SendNotFound markup per UI-SPEC.
   - Use `<?= $this->element('icon', ['name' => 'back', 'size' => 22]) ?>` for the back chevron in the AppBar.
   - Use `<?= h($url) ?>` for the URL pill (escaped).

   ```php
   }
   ```
