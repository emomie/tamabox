# Plan 08-04 — EDGE-03: Send overflow live feedback (counter color + chip + disabled CTA)

## Goal

Wire JavaScript live feedback for the 2000-character overflow state on `templates/Messages/send.php`: when the textarea exceeds 2000 characters, the counter turns warm-700, an "is-overflow" class is added to the textarea (triggering warm border + cream bg from §I.4), an "is-visible" class is added to the "長すぎます" chip (toggling display from none to inline-flex), and the submit button gains the `disabled` attribute. Server-side guard already exists; this is a progressive enhancement (D-09).

## Risks

- Inline `<script>` removal: ensure the dynamic counter still updates. The new `send-counter.js` covers everything the inline script did, plus the overflow state.
- The chip is `aria-live="polite"` — confirm screen-reader announcements don't fire on initial paint (it should be display:none initially, which suppresses announcement until visible).
- `data-send-submit` selector — only one submit button in the form. If multiple, scope `querySelector` to the form. Single submit confirmed in current send.php.
- The disabled state on submit blocks all submission, including network errors. Defense in depth: server guard re-checks `mb_strlen > 2000`.
